# Zybooks assignment:
The project is an opportunity for you to gain some experience with an open-ended project of interest to you that you could discuss in an interview or put on your resume
For the course thus far, you have been given templates for testing, makefiles, etc.  For this assignment, we want you to demonstrate that you can set up a project from scratch.  It must minimally contain the following:

    Project source code
    Some kind of unit testing
    A Makefile with targets to run unit testing (make test) and run a demo (make demo)
    Some kind of timing analysis (execution times for a least two different-sized data sets)
    A README.md markdown file with at least 150 words that explains your project and analysis.

You can implement the project in either C or Python, but in general, we'd prefer Python
If you've never done data analysis and visualization in Python before, we strongly recommend a project that does that, in particular using the follow Python libraries

    numpy
    matplotlib
    pandas

You should only consider an AI project if you have done data analysis and visualization with the above-mentioned Python libraries before.  If you want to do an AI project, we strongly recommend using pytorch.
