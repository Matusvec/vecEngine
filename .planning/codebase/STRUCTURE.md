## Directory Purposes

**Project Root:**
- Purpose: Application entry point and build configuration
- Contains: Main executable source, CMake config, build targets
- Key files: `main.cpp`, `CMakeLists.txt`

**include/:**
- Purpose: Local header directory (currently only GLAD)
- Contains: GLAD OpenGL loader headers and KHR platform definitions
- Key files: `include/glad/glad.h`, `include/KHR/khrplatform.h`

**src/:**
- Purpose: Reserved for modular source files (currently empty)
- Contains: Intended location for future C++ source modules
- Key files: None currently

**shaders/:**
- Purpose: Reserved for external shader files (currently empty)
- Contains: Intended location for .vert, .frag GLSL files (not yet extracted)
- Key files: None currently

**vendor/:**
- Purpose: Third-party dependencies
- Contains: GLAD OpenGL function loader (compiled .c implementation)
- Key files: `vendor/src/glad.c` (152KB OpenGL loader)

**vendor/include/:**
- Purpose: Headers for external libraries
- Contains: GLAD and KHR headers linked into project
- Key files: `vendor/include/glad/glad.h`, `vendor/include/KHR/khrplatform.h`

**build/:**
- Purpose: CMake output directory (generated, not committed)
- Contains: Compiled objects, final executable
- Key files: `build/flight` (final executable)

**.planning/codebase/:**
- Purpose: GSD codebase analysis documents
- Contains: ARCHITECTURE.md, STRUCTURE.md, CONVENTIONS.md, etc.
- Key files: Analysis documents generated for future reference

## Naming Conventions

**Files:**
- Main executable source: `main.cpp`
- CMake config: `CMakeLists.txt` (standard convention)
- Vendor source: snake_case (e.g., `glad.c`)
- Shader files: Not yet extracted (placeholder: `shaders/`)

**Directories:**
- Include directories: lowercase plural (include, vendor, src, shaders, build)
- Subdirectories in vendor/include: match library name (glad, KHR)

**Functions:**
- camelCase: processInput(), compileShader(), createShaderProgram(), framebufferSizeCallback()
- Pattern: Descriptive verb-noun structure

**Variables:**
- Global scene state: camelCase (cubePos, moveSpeed, deltaTime, lastFrame)
- GLSL uniform names: camelCase (model, view, projection)
- Local variables: camelCase (window, shader, VAO, VBO, EBO, vertices, indices)
- OpenGL handles: unsigned int suffixed with semantic (shaderProgram, VAO, VBO, EBO)

**Types:**
- GLM math types: glm::vec3, glm::mat4 (external library convention)
- GLFW types: GLFWwindow* (external library convention)

## Where to Add New Code

**New Feature (e.g., additional geometry, animation):**
- Primary code: `main.cpp` (extend main() or add helper functions)
- Location guideline: Add functions before main(), data before functions

**New Component/Module (e.g., shader manager, input handler abstraction):**
- Implementation: Create new file in `src/` (e.g., `src/shader_manager.cpp`)
- Header: Create corresponding `include/shader_manager.h`
- Update: Modify `CMakeLists.txt` to add source to add_executable()

**Utilities (e.g., matrix helpers, color definitions):**
- Shared helpers: Create `src/utils.cpp` and `include/utils.h`
- Pattern: Utility functions as free functions, not class-based

**Shaders (e.g., new material shaders):**
- Location: `shaders/[name].vert` and `shaders/[name].frag`
- Loading: Eventually read from files; currently embedded as string literals in `main.cpp`

**Tests:**
- When framework is selected, create `tests/` directory
- Naming: `tests/[module].test.cpp`
- Integration: Add test target to `CMakeLists.txt` with gtest or Catch2

## Special Directories
